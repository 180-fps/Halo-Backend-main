# Reverse Backend

Fortnite private server backend written in Ruby using Sinatra.

## Stack

- Ruby + Sinatra
- Puma (web server)
- dotenv

## Setup

```bash
bundle install
ruby src/index.rb
```

Runs on port `3551` by default. Change it in `.env`.

## Routes

| Service | Endpoints |
|---|---|
| Auth | `/account/api/oauth/token`, `/verify`, `/sessions/kill` |
| Account | `/account/api/public/account/:id`, `externalAuths`, `enabled_features` |
| MCP | `/fortnite/api/game/v2/profile/:accountId/client/:operation` |
| Lightswitch | `/lightswitch/api/service/Fortnite/status`, `bulk/status` |
| Version | `/fortnite/api/v2/versioncheck`, `calendar/v1/timeline` |
| CloudStorage | `/fortnite/api/cloudstorage/system`, `user/:id` |
| Keychain | `/fortnite/api/storefront/v2/keychain` |
| ContentPages | `/content/api/pages/fortnite-game` |
| DataRouter | `/datarouter/api/v1/public/data` |

## Athena Profile

The MCP route serves a full Athena profile generated by [AthenaProfileGenerator](https://github.com/LawinServer-Public/AthenaProfileGenerator).

## Season

Configured for **Chapter 1 Season 1 - Chapter 3 Season 1**. Change your season in `Halo-Backend-main\.env` to target a different build.
